# Security Policy

## Supported Versions

Only the most recent release of PhotoVault is actively maintained.  
Older versions may work but do not receive security or dependency updates.

| Version | Supported |
|----------|------------|
| 5.x.x (main) | ✅ |
| 4.x.x | ⚠️ Limited |
| < 4.0 | ❌ Unsupported |

---

## Reporting a Vulnerability

If you discover a security issue in PhotoVault, please do **not** open a public issue.  
Instead, contact the maintainer directly at:

📧 **rogsor80@gmail.com**

Include a clear description of:
- The type of vulnerability (e.g., XSS, injection, key exposure)
- Steps to reproduce or sample code
- Which environment or branch is affected

You will receive an acknowledgment within **48 hours**,  
and a resolution or patch plan within **7 days** for valid reports.

---

## Disclosure Policy

Security vulnerabilities will be disclosed publicly **only after** a fix has been deployed.  
Contributors and testers may receive early access to patches under embargo.
