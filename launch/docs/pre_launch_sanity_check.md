# Pixtr – Pre-Launch Sanity Check (5 min)

Complete this checklist once before submitting to App Store and Google Play.

---

## 1. Build & App Behavior (2 min)

- [ ] App launches without crash
- [ ] No debug banners or console warnings visible
- [ ] Empty state screens look intentional
- [ ] Loading states are calm and non-blocking
- [ ] Error messages are user-friendly

---

## 2. Core Flows (2 min)

- [ ] Sign up / login works
- [ ] Upload photos works
- [ ] Create album works
- [ ] Browse photos works
- [ ] Memories view loads correctly
- [ ] Photo editor opens and saves
- [ ] Secure Vault can be created and opened
- [ ] Wrong Vault password shows correct error

---

## 3. Privacy & Trust (30 sec)

- [ ] Privacy Policy link opens correctly
- [ ] Terms of Service link opens correctly
- [ ] Vault warning text visible and clear
- [ ] No misleading security language
- [ ] No references to password recovery

---

## 4. Store Content (30 sec)

- [ ] App name matches build
- [ ] Screenshots match current UI
- [ ] Screenshot text readable on small screens
- [ ] Store descriptions match app behavior
- [ ] No references to unreleased features

---

## 5. Final Gut Check (30 sec)

Ask yourself:

- Does this feel calm?
- Does this feel trustworthy?
- Does this feel finished?

If yes → submit.

---

## Status

When all boxes are checked, Pixtr is ready for review.
