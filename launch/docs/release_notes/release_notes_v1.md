# Pixtr – Release Notes

## Version 1.0.0

Welcome to Pixtr.

This initial release introduces a calm, privacy-first photo experience
designed to protect and preserve your memories.

### What’s included

- Secure photo storage
- Album organization
- Memories from previous years
- Simple photo editing tools
- Secure Vault with client-side encryption

Pixtr is built with clarity, stability, and privacy as core principles.
Your photos remain yours — always.
