# Pixtr – Store Submit Checklist

This checklist ensures Pixtr is fully prepared for submission to both
Apple App Store and Google Play, with special attention to privacy,
security, and Vault encryption.

---

## 1. Shared (Both Stores)

### Branding & Assets

- [ ] App name finalized and consistent
- [ ] App icon (1024×1024) uploaded
- [ ] Screenshot set finalized (6 images)
- [ ] Screenshot order verified (Hero → Vault)
- [ ] No placeholder text or debug UI visible

### Legal & Trust

- [ ] Privacy Policy published and accessible via URL
- [ ] Terms of Service published and accessible via URL
- [ ] Links added in store listings
- [ ] Vault and encryption explained clearly in public copy

### Functionality

- [ ] App launches without crashes
- [ ] Core flows tested:
  - [ ] Upload photos
  - [ ] Create albums
  - [ ] Browse photos
  - [ ] Memories view
  - [ ] Photo editing
  - [ ] Vault setup and access
- [ ] Error handling verified (offline, failed upload, wrong password)

---

## 2. Apple App Store Checklist

### App Information

- [ ] App Name (≤ 30 characters)
- [ ] Subtitle (≤ 30 characters)
- [ ] Description completed
- [ ] Keywords (≤ 100 characters)
- [ ] Promotional Text (optional)
- [ ] What’s New (v1.0)

### Screenshots

- [ ] 6.7-inch screenshots uploaded (primary)
- [ ] Screenshots readable at small sizes
- [ ] No marketing claims that cannot be verified
- [ ] No references to unreleased features

### Privacy & Security (Critical)

- [ ] Privacy Policy URL added
- [ ] Data collection disclosures completed
- [ ] Vault encryption explained accurately
- [ ] No claim of recoverable passwords
- [ ] Biometric usage declared correctly

### App Review Notes (Strongly Recommended)

- [ ] Review notes included explaining:
  - Client-side encryption
  - Vault password handling
  - Non-recoverable encrypted content
  - Optional biometric unlock
- [ ] Clear explanation that Pixtr cannot access Vault photos

### Compliance

- [ ] No misleading security claims (e.g. “military-grade”)
- [ ] No competitor references
- [ ] No references to pricing outside allowed areas
- [ ] App complies with App Store Review Guidelines

---

## 3. Google Play Store Checklist

### Store Listing

- [ ] App Name finalized
- [ ] Short Description (≤ 80 characters)
- [ ] Full Description completed
- [ ] Feature Graphic uploaded
- [ ] Keywords optimized
- [ ] What’s New (v1.0)

### Screenshots

- [ ] Phone screenshots uploaded (minimum 2, recommended 6)
- [ ] Consistent visual style
- [ ] Text readable on small screens
- [ ] No excessive text overlays

### Privacy & Data Safety

- [ ] Privacy Policy URL added
- [ ] Data Safety form completed accurately
- [ ] Vault encryption described correctly
- [ ] No claim of server-side access to Vault photos

### Compliance

- [ ] App content rating completed
- [ ] Target audience declared correctly
- [ ] No misleading claims
- [ ] No unnecessary permissions requested

---

## 4. Final Pre-Submit Checks

- [ ] Version number confirmed (v1.0.0)
- [ ] Build uploaded and processed successfully
- [ ] All required metadata fields completed
- [ ] Preview build tested one last time
- [ ] Screenshots and text reviewed for consistency

---

## 5. Post-Submission

- [ ] Monitor review status daily
- [ ] Prepare to respond to reviewer questions
- [ ] Be ready to clarify Vault encryption and password handling
- [ ] Plan soft launch announcement after approval

---

## Status

When all items are checked, Pixtr is considered **Ready for Submission**.
